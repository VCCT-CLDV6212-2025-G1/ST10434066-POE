This project is the **ABC Retail Storage App**, built as part of the CLDV6212 module.  
It demonstrates the use of **Azure Storage services** in an ASP.NET Core MVC application.

## Features 
- **Azure Tables**
- **Azure Blob Storage**
- **Azure Queue Storage**
- **Azure File Shares**
- **Web App Deployment**
  
## Technologies
- ASP.NET Core MVC (.NET 8)
